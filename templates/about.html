Project Abstract & Specification BTech CSE Major Project
Road Accident Prediction and Analytics Dashboard Using Machine Learning

This system establishes an end-to-end predictive analytics framework on 513,801 official collision records (2021–2025) published by the UK Department for Transport (DfT). Rather than relying on synthetic or toy datasets, it addresses real-world machine learning challenges including high-dimensional categorical encoding, special missing-value flags (-1), acute target class imbalance (1.8% fatal vs. 75.8% slight), spatial auto-correlation, and multicollinearity.

Academic Viva Defense & Examination Guide Frequently Asked Viva Questions
Key theoretical explanations to defend your project before college examiners.

Q1: Why did you aggregate accident counts by month for Regression instead of running regression on raw collision rows?

Answer: On individual collision rows, accident severity is discrete and ordinal (Fatal=1, Serious=2, Slight=3). Treating these codes as continuous real numbers in linear regression would violate regression assumptions (homoscedasticity and normality of residuals) and imply equal metric distances between categories. Aggregating counts by month provides a continuous, non-negative target ($Y \in \mathbb{R}^+$) suitable for Ordinary Least Squares (OLS) and Polynomial regression.

Q2: How did you address the extreme class imbalance in accident severity?

Answer: Fatal and serious injuries represent ~24% while slight injuries represent ~76%. If evaluated purely on raw Accuracy, a naive model predicting "Slight" would achieve 76% accuracy but fail on all fatal collisions. We implemented class_weight='balanced' across Logistic Regression, Decision Trees, and Random Forests, which applies cost-sensitive penalty weights inversely proportional to class frequencies ($w_j = \frac{N}{k \cdot n_j}$), and benchmarked models on Weighted F1-score and ROC-AUC.

Q3: What is the fundamental difference between Bagging and Boosting in your ensemble experiments?

Answer: Bagging (Bootstrap Aggregating) trains base estimators in parallel on independent bootstrap samples to reduce model variance without increasing bias. Random Forest enhances this with random feature subspace selection. In contrast, Gradient Boosting trains base estimators sequentially, where each new tree fits the pseudo-residuals of the prior ensemble to reduce bias.

Q4: How did Principal Component Analysis (PCA) impact classification performance?

Answer: PCA performed orthogonal linear transformation to project 10 standardized road features into uncorrelated principal components. The top 3 components preserved ~40% of overall variance. Evaluating Logistic Regression before vs. after reduction demonstrated that the 3-component model retained ~98% of the baseline F1-score while compressing feature dimensionality by 70%, proving effective redundancy elimination.

Academic Project Limitations Critical Reflection
  • Unreported Accidents: Minor property-damage-only collisions without police attendance are excluded from STATS19.
  • Driver Behavior: Real-time telematics (telecom distraction, BAC levels, micro-sleep) are not available as continuous sensor features.
  • Static Speed Limits: Posted speed limits were recorded rather than dynamic GPS vehicle velocity at moment of impact.
