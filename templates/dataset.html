Pipeline Step Issue Identified Remediation / Technique Applied Academic Justification
Temporal Selection 1979–2000 data lacks GPS coordinates and modern vehicular safety tech. Filtered to 2021–2025 (513k records). Preserves modern road context and 99.9% complete geographical attributes.
Special Missing Code (-1) DfT uses integer -1 to denote unrecorded/unknown attributes. Mapped -1 to explicit 'Unknown' category / median imputation. Prevents algorithms from treating -1 as a negative ordinal value.
Feature Engineering Time is recorded as HH:MM string; Date as DD/MM/YYYY. Extracted numerical hour (0–23) and month (1–12). Enables capturing diurnal cycles and monthly seasonal patterns.
Target Imbalance Fatal accidents comprise only 1.8% of records; Slight comprises 76.2%. Formulated binary severe indicator (Fatal+Serious vs Slight) + balanced weighting. Prevents machine learning models from collapsing into a trivial majority classifier.
Stratified Sampling Full 500k dataset causes $O(N^2)$ memory bottlenecks for distance/kernel models (KNN, SVM). Extracted 100,000-row stratified sample preserving exact class proportions. Ensures rapid training, real-time response, and reproducible viva demonstrations.
